# AXT-000 — Fundação Documental e Arquitetural

Versão: 1.0  
Data de consolidação: 16/08/2026  
Status: **Concluída**

## Objetivo

Estabelecer a base oficial do Axiom Tools antes das Sprints funcionais.

## Entregas consolidadas

- repositório oficial `Axiom_Tools`;
- `README.md`;
- `pyproject.toml` com Python 3.12 ou superior;
- estrutura inicial `src/`, `tests/`, `config/`, `scripts/` e `docs/`;
- consolidação oficial do projeto;
- arquitetura oficial;
- decisões permanentes;
- roadmap oficial;
- convenção documental `DEC-*` para decisões e `AXT-*` para Sprints.

## Fora de escopo

A AXT-000 não implementa regra funcional de:

- estrutura de pastas;
- Login/Dashboard;
- cadastro de clientes;
- OCR;
- competências;
- conferência;
- impressão;
- integrações externas.

## Critério de conclusão

A fundação é considerada concluída porque a documentação e estrutura de projeto necessárias para iniciar a primeira Sprint funcional estão registradas no repositório.

## Observação

A AXT-000 não deve ser “reexecutada” por um novo executor. O próximo trabalho funcional começa na AXT-001.
