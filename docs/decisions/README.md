# Decisões do Projeto

Esta pasta guarda decisões permanentes do Axiom Tools.

Cada decisão relevante de arquitetura, segurança, armazenamento, OCR, classificação documental, integração ou comportamento operacional deverá ser registrada aqui antes ou junto da implementação.

## Regras permanentes já estabelecidas

1. Documentos originais não devem ser excluídos automaticamente.
2. A movimentação e classificação de arquivos deve manter rastreabilidade.
3. Resultados de OCR e classificação automática devem admitir conferência humana.
4. Autenticações e desafios humanos de portais governamentais não devem ser contornados.
5. Caminhos de origem, destino e estruturas de clientes devem ser configuráveis.
6. O projeto deve permanecer independente e modular.
