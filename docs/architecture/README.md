# Arquitetura — Axiom Tools

A arquitetura oficial vigente está em:

- `ARQUITETURA_OFICIAL_AXIOM_TOOLS.md`

## Regras de leitura

- a arquitetura define limites, camadas e princípios;
- as decisões `DEC-*` detalham regras permanentes;
- as Sprints `AXT-*` determinam quando cada capacidade é implementada;
- `docs/STATUS_ATUAL.md` informa qual Sprint está ativa.

A implementação funcional atual deve respeitar integralmente a arquitetura versão 2.0 e não antecipar módulos de Sprints futuras.
